# Life Relocation Reset Project Hub

This folder is the local home for the Life Relocation Reset / "Novaya Glava" business project.

The goal is to move from temporary no-code assets, including the Canva landing page and Google Form, into a professional website and funnel that can support trust, conversion, analytics, and future content growth.

## Source Of Truth

Start here:

- `00-context/imported-chatgpt-project-context.md` - imported project history and strategic brief from prior ChatGPT work.
- `00-context/README.md` - how to add new context from future ChatGPT sessions.
- `04-website/README.md` - initial website build direction.
- `06-analytics/README.md` - behavior tracking and funnel measurement notes.

## Folder Map

- `00-context` - imported ChatGPT history, future exports, decisions, open questions.
- `01-brand` - brand voice, names, positioning, visual references.
- `02-offer` - service packaging, pricing, booking, payment, FAQ.
- `03-content` - Instagram, email, long-form copy, resources.
- `04-website` - website source, architecture, copy, implementation notes.
- `05-quiz-funnel` - quiz questions, result logic, lead capture, scoring.
- `06-analytics` - tracking plan, events, dashboards, audience behavior.
- `07-assets` - approved images, video, logos, fonts, design assets.
- `08-research` - market, competitors, legal/source notes, audience research.
- `09-operations` - admin workflows, launch checklists, templates.

## Current Important Boundaries

The business is a strategic coaching and clarity offer based on lived international experience. It is not a law firm, immigration agency, tax adviser, visa processor, or financial adviser.

The website should avoid promises of visas, jobs, residency, income, legal outcomes, or guaranteed introductions.

## Working Process

When new work is created in ChatGPT online, export or paste the useful output into `00-context` or the relevant topic folder. Codex can then turn that content into structured website, quiz, analytics, and product artifacts.
