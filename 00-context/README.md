## How To Add Future ChatGPT Context

Codex cannot automatically read private ChatGPT browser history. To bring future online ChatGPT work into this project, add one of these:

- exported ChatGPT conversation files;
- pasted markdown summaries;
- screenshots or copied text from specific conversations;
- links or notes that describe final decisions.

Recommended naming:

- `YYYY-MM-DD-topic.md`
- `YYYY-MM-DD-chatgpt-export-title.md`

## Source Priority

Use this order when sources conflict:

1. Latest direct decision from Masha.
2. Live Canva site and Google Form, until replaced.
3. Imported ChatGPT project context.
4. Older drafts and brainstorms.
