# Quiz And Funnel Notes

The current Google Form is the initial source of truth for the quiz question set until it is fully inventoried and migrated.

## Intended Direction

Build a native quiz that can support:

- editable questions and answer options;
- scoring logic;
- result routing;
- email / lead capture;
- analytics events;
- privacy-aware storage;
- clear calls to action into the 1:1 session.

## Known Result Types

From the imported context, the planned result types are:

- The Explorer
- The Builder
- The Reinventor
- The Freedom Seeker

These should be treated as working concepts until the live form and latest owner decisions are reviewed.
