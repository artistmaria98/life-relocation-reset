# Website Build Brief

The website should replace the current Canva landing page and Google Form with a professional, maintainable experience.

## MVP Direction

The first version should focus on:

- a strong English-first landing experience;
- an "About Masha" trust section or page before the quiz;
- a native quiz / lead magnet;
- result pages that route people toward the 1:1 Life Relocation Reset session;
- clear booking and payment flow;
- privacy-conscious analytics for understanding audience behavior.

## Required Pages Or Views

- Home
- About Masha
- Quiz
- Quiz result pages
- Offer detail / booking
- FAQ
- Privacy / legal disclaimer

## Important Product Rules

- Do not scrape or reuse Canva-generated code as production source.
- Do not embed Google Forms as the final intended quiz.
- Keep editable content in structured data or configuration where practical.
- Make copy, offers, pricing, and legal boundary language easy to update.
- English is the initial website priority. Russian and other language versions can come later.

## Pre-Build Review

Before replacing the existing public funnel, inventory the live Canva site and Google Form and compare them against the imported context brief.
