# Website Prototype

This is the first local professional MVP for Life Relocation Reset.

Open:

- `index.html`

## What Is Included

- English-first landing page.
- Project-owned generated hero image.
- About Masha section.
- Native quiz with multi-question scoring.
- Four result types.
- Offer section with current launch price.
- FAQ and legal boundary copy.
- Lightweight demo analytics stored in `window.dataLayer` and browser `localStorage`.
- Consent banner for analytics acceptance before production-style tracking.

## Current Limitations

- No backend yet.
- Quiz submissions are not sent anywhere.
- Booking currently points to Instagram until booking/payment tools are confirmed.
- Analytics are demo/local only until the analytics provider and consent approach are chosen.
- Russian and other language versions are intentionally deferred.

Create a refined, understated world map background texture for a premium international relocation and life strategy website. The map should feel elegant, quiet, and sophisticated, like a faint ink map printed on warm paper. No labels, flags, pins, routes, or loud travel-agency styling.
