# Analytics And Funnel Measurement

The new website should make it possible to understand audience behavior more clearly than Canva and Google Forms allow.

## What To Measure

- landing page visits;
- scroll depth and section engagement;
- calls to action clicked;
- quiz started;
- quiz completed;
- result type generated;
- email or contact captured;
- booking page opened;
- booking started;
- payment or consultation request completed;
- outbound social clicks.

## Privacy Notes

The project serves people considering relocation and life change, so data handling should feel trustworthy and conservative.

Track useful behavior, but avoid collecting unnecessary sensitive information. Any legal, immigration, financial, or personal data should be treated carefully and explained clearly.

## Tool Decisions To Confirm

- analytics provider;
- consent banner requirements;
- booking provider;
- payment provider;
- email / CRM provider;
- where quiz answers and leads will be stored.
